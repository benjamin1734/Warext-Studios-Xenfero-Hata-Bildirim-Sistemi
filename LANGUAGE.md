# Language support / Dil desteği

Bug Reporting now follows XenForo's native language selection. Import `languages/Turkish.xml` or `languages/English.xml` into the matching XenForo language (or a child language).

System labels, buttons, ACP text, statuses and diagnostics UI are translated. User-written bug descriptions, replies and internal notes are content and are not automatically translated.

Yeni kullanıcıya görünen sabit metinler XenForo phrase sistemi kullanılmadan template/PHP/JS içine eklenmemelidir.
